# US Fresh Jobs Platform

A continuously updated U.S. job data platform. Not a website with 100 jobs — the database
preserves every qualifying job, and the UI provides fast access to the newest and most
relevant ones.

**Current state: Milestone 3 complete.** Foundation, schema, operational surface, source
abstraction, object storage, sync tracking and the OpenJobData connector are built and
verified — the connector against the live bucket.

---

## Read this first

[`docs/00-source-verification.md`](docs/00-source-verification.md) records what was
**measured** about the OpenJobData source, not assumed. Several findings changed the
architecture:

- The `minimal` dataset variant has **no city, state, salary or description** — only a
  free-text `country`. The `full` variant is therefore mandatory.
- Excluding the `entire_json` column via Parquet column projection **halves** the daily
  download: 238 MB → 120 MB.
- `posted_at` is **NULL for 19.3%** of rows and contains **real future dates** (observed
  34 days ahead). It can never be used naively for "posted 18 minutes ago".
- The publisher **skips days** — and the gap sets differ between variants. Discovery must
  diff a directory listing, never iterate a date range.
- Publication is **same-day** but the upload hour varies (06:33–14:15 UTC), so a fixed-time
  cron would sometimes run before the day's file exists.
- The `state` field carries **non-US values** (`Quebec`, `Maharashtra`), so a populated
  state never implies a US job.
- A single day's delta carries **~62,000 U.S. rows**, which is why ingestion has no row cap.

Re-verify at any time — the source can change:

```bash
python scripts/verify_source.py
```

## Quick start

```bash
make init            # create .env.development from the template
make up              # postgres + redis + minio + api
make migrate         # apply the database schema
make test            # 278 tests
make layering        # source-isolation guard
```

Then: <http://localhost:8000/docs>

Without Docker, point `DATABASE_URL` at a local PostgreSQL 17 and run `make migrate && make test`.

`make help` lists all targets.

```
HF bucket ──► SourceConnector ──► object storage ──► ingestion worker ──► PostgreSQL
                                                            │                 │
                                                     validate/normalize    FastAPI
                                                     locate/dedupe            │
                                                     lifecycle             Next.js
```

Full detail, ERD, security model and deployment stages:
[`docs/01-architecture.md`](docs/01-architecture.md).

**Stack.** Next.js + TypeScript + Tailwind · FastAPI + Pydantic · Polars/PyArrow ·
PostgreSQL 17 · Redis · Celery · S3-compatible storage · Docker.

**The rule that keeps sources swappable:** all OpenJobData knowledge lives inside
`workers/ingestion/ingestion/connectors/openjobdata/`. CI fails the build if `openjobdata`,
`huggingface` or `hf://` appears anywhere else — run `make layering` to check locally. It
caught three real leaks the day it was added.

## Data principles

These are enforced in code and in the database, not just documented:

1. **`posted_at` is never overwritten by `first_seen_at`.** Both are shown, labelled, in
   the UI. Timestamps are never fabricated.
2. **Seven distinct timestamps** — `posted_at`, `first_seen_at`, `last_seen_at`,
   `last_updated_at`, `source_fetched_at`, `close_at`, `closed_at`. Collapsing any two
   loses information the source actually provides.
3. **Jobs are never deleted.** They transition between `ACTIVE`, `EXPIRED`, `REMOVED` and
   `UNKNOWN`, and every transition is recorded in `job_events`.
4. **Nothing is silently discarded.** Every rejected row is stored in `sync_errors` with a
   reason from a closed enum of 14.
5. **Ingestion is idempotent.** Reprocessing a file cannot create duplicates —
   `job_sources (source, external_job_id)` is a database UNIQUE.
6. **No artificial limits.** If a day has 62,000 qualifying U.S. jobs, all 62,000 are stored.
